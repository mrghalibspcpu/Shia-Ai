# Anonymous install records

One line (or one small file) per install, e.g.:

SV-XXXXXX | installed: 2026-10-18 | last_active: 2026-10-18 | status: active

Only the random anonymous ID and dates — never any personal information.
A record whose owner uninstalls / stops being active is marked
`status: removed`, so `active_users` = records still marked `active`.
