# Dock, More Features, and the home sections (1.10.1)

This note replaces the dock layout in `docs/home-dock-1-10.md`. The 1.10 layout
(کتب, تلاش, آخری مطالعہ, قبلہ نما, ڈاؤن لوڈ in the panel) is superseded.

## The bottom panel

Five buttons on a pure black bar, each an icon in a 46 px rounded square
(`HomeDock` and `_DockButton` in `app/lib/widgets/reading_hub.dart`).

| Button | Action |
|---|---|
| Home | Home tab; on top of a page, pops back to the home screen |
| تلاش | Search tab; on top of a page, opens search above it |
| محفوظات | Opens the saved items (bookmarks and notes) above the current page |
| مزید خصوصیات | Opens the More Features sheet |
| ترتیبات | Opens settings above the current page |

The routing is `_runHubAction` in `app/lib/main.dart`. The radial menu over a
page uses the same five destinations and the same routing.

## More Features

`showMoreFeaturesSheet` in `app/lib/widgets/more_features.dart` shows a list of
`MoreFeature` items. The current items are defined in `_moreFeatures` in
`app/lib/main.dart`:

- قبلہ نما (Qibla compass)
- آخری مطالعہ (last-seen list)

An item closes the sheet first and then runs its action. To add a feature, add
one `MoreFeature` to that list.

## Settings

ترتیبات starts with a **ڈیٹا** section. Its tile opens the download screen
(`DataScreen`), so download is no longer a bottom-panel button.

## Home sections

`LibraryHomeScreen` in `app/lib/screens/library_screen.dart` shows, after the
prayer card, the tasbeeh and the download and indexing notices:

1. قرآنِ کریم (`QuranHomeScreen`)
2. احادیث (`HadithBooksScreen`, a grid of the hadith books)
3. مفاتیح الجنان و صحیفہ سجادیہ (`DuaCollectionScreen`)
4. نہج البلاغہ (`BalaghaHomeScreen`)
5. دینی مسائل (احکام و فتاویٰ) (`FatawaCollectionScreen`)

Each is a full-width `_HomeSectionCard`. A section whose books are not installed
shows a download icon and opens the data screen instead.

## Last-seen fix

Tapping an entry in آخری مطالعہ used to await the reader before closing the
sheet, so the sheet stayed on the stack under the reader. Returning through the
radial menu then left the home screen blank until the app was reopened.

Now `LastReadTile` runs `onBeforeOpen` first (the sheet pops), then opens the
reader from `openContext`, which is the home page that opened the sheet. The
radial **Home** action also refreshes the home shell.

## Home prayer card and tasbeeh

- The prayer card is centred. The place name and its detail fade out 10 seconds
  after the home opens (a timer in `_HomePrayerBannerState`, cancelled on
  dispose). The pin icon stays.
- The tasbeeh is a 290 px circle (`HomeTasbeehCard`). The count ring is centred,
  with reset and + on either side, the zikr under the ring, and today's count at
  the bottom. Its title and the swap and open buttons sit along the top.

## Checks

The change was made without a Flutter SDK in the sandbox. Proof is the CI run:
`flutter analyze`, `flutter test` (the layout test renders the home card at four
times of day and with a large font), and the release APK build. The Dart checker
(`python3 scripts/check_dart.py`) passes, including the syntax parse.
