ShiaVerse — Privacy Policy

Effective date: 20 October 2026 • Version 1.21.0 (30) • Package: com.shiaai.app • Developer: ShiaVerse Team
Contact: shiaverse.support@gmail.com • Publisher page: github.com/mrghalibspcpu/ShiaVerse

Summary: ShiaVerse is an offline-first Shia Islamic library. The app does not create user accounts, does not run ads, does not include analytics or tracking SDKs, and does not send your reading activity to a developer server. Two network features exist: (1) an optional on-demand download of the book databases from GitHub, and (2) loading street-map tiles for the Qibla page. Your location is used only on-device for prayer times and Qibla.

1. What the app does

ShiaVerse provides offline reading of the Quran with Urdu translation & tafseer, Mafatih al-Jinan, Sahifa Sajjadiyya, Nahj al-Balagha, 14 Urdu/Arabic hadith books, the Athna-Ashari encyclopedia, fatawa, prayer times, Hijri calendar, Qibla compass/map, tasbeeh and search/bookmarks/notes. Except for the corpus download and map tiles described below, all features work fully offline after the first download.

3. Network data — what actually leaves the device

3.1 Corpus download (GitHub)

On first launch each book (Quran, hadith books, etc.) is listed as “not installed”. Tapping Download fetches <name>.db.gz from:

  • Primary: https://github.com/mrghalibspcpu/ShiaVerse/releases/download/databases-v1/
  • Fallback: https://raw.githubusercontent.com/mrghalibspcpu/Shia-Ai/main/assets/ (legacy pinned URL kept in the manifest)

The app sends a normal HTTPS GET with resume support (Range). The server (GitHub) sees your IP, request time, file name and User-Agent as with any GitHub download. GitHub’s privacy statement applies: docs.github.com — GitHub General Privacy Statement. The download is hashed (SHA-256) against assets/database-manifest.json and unpacked locally; a mismatched file is deleted and never opened. No personal data is added to the request.

You can use the app without this download if you build it with python3 scripts/prepare_databases.py --output app/assets/databases — then the APK already contains the corpus and makes no download request.

3.2 Qibla street map (OpenStreetMap / Esri)

The Qibla page shows a north-up street map with your position, a line to the Kaaba and an optional heading cone. Map tiles are fetched from (in order):

  1. https://tile.openstreetmap.de/{z}/{x}/{y}.png — German OSM mirror, operated by FOSSGIS e.V.
  2. https://a.tile.openstreetmap.fr/hot/{z}/{x}/{y}.png — French OSM-FR “Humanitarian” tiles.
  3. https://server.arcgisonline.com/ArcGIS/rest/services/World_Street_Map/MapServer/tile/{z}/{y}/{x} — Esri.

The previous CARTO CDN provider (basemaps.cartocdn.com) has been removed in 1.21.1 because it began requiring an API key and returned an “API key required” tile. The tile servers see your IP and the requested tile coordinates (which coarse-locate your viewport, not a precise GPS fix). Their policies apply:

  • OpenStreetMap: osmfoundation.org — Privacy Policy
  • Esri: esri.com — Privacy

The map keeps a small attribution “© OpenStreetMap · © Esri” on screen as required. If you are offline the map shows a faint graticule and the Qibla bearing/distance remain correct — the bearing is computed locally from your coordinates and the Kaaba (21.4225° N, 39.8262° E) using the WGS-84 great-circle formula, no network needed.

3.3 No other network calls

The app makes no other network requests: no analytics endpoints, no crash reporters, no ad networks, no social SDKs. The AI-chat/Gemini integration was removed before 1.0; there are no API keys or backends.

4. Data stored on your device

All of the following stay on your device and are deleted if you clear app data or uninstall:

  • Downloaded SQLite databases under the app’s private storage (/data/data/com.shiaai.app/).
  • Bookmarks, notes, reading positions (“Last seen”), and tasbeeh counters — saved via SharedPreferences and a local SQLite search index.
  • Chosen city, prayer-calculation settings (Jafari/Leva Qum method), and notification preferences.
  • Cached search index (search_docs + FTS) built from the local books.
  • Map tile cache (handled by Flutter’s image cache / HTTP cache) — cleared with the system cache.

There is no “login”, no cloud sync and no restore code. If you want to keep your corpus after an update, do not use “Clear data”; just tap the update APK — successive CI-signed builds share the same signature so adb install -r or tapping the APK preserves the databases.

5. Data sharing

We do not sell, rent or otherwise share personal data. The only recipients of technical data are the tile and download hosts named in §3, as part of delivering the feature you requested. Those hosts process your IP under their own policies; we do not receive copies of their logs.

6. Children’s privacy

ShiaVerse contains religious texts and no user-generated public content. It is suitable for all ages and does not knowingly collect information from children. If you believe a child has provided personal information through an app store review or email, please contact us and we will delete it.

7. Your choices

  • Deny location: Prayer times and Qibla still work with a manually selected city (the bearing defaults to the city centre). The map still loads tiles for the chosen city.
  • Block network: The app remains fully functional for reading, search, bookmarks and prayer times. Map tiles and new book downloads will not load.
  • Delete data: Android Settings → Apps → ShiaVerse → Storage → Clear data removes the corpus, search index, bookmarks and settings. Uninstall does the same.

8. Security

Downloads are verified with SHA-256 before opening; corrupt files are deleted. Databases are opened read-only except for the search index. The manifest (database-manifest.json) lists every expected size, hash, row count and download URL, and is checked by scripts/prepare_databases.py and the in-app verifier.
