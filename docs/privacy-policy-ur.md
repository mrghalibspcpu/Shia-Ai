# ShiaVerse — رازداری کی پالیسی

**ایپ کا نام:** ShiaVerse (اینڈرائیڈ پیکج `com.shiaai.app`)  
**اشاعت کنندہ:** جو تعارف ایپ کی اسٹور لسٹنگ پر درج ہے  
**آخری تجدید:** 16 اکتوبر 2026

ShiaVerse ایک آف لائن شیعہ مطالعہ گاہ ہے: قرآنِ کریم اردو ترجمہ اور تفسیری
حواشی کے ساتھ، مفاتیح الجنان، نہج البلاغہ، صحیفہ سجادیہ، دو مجموعے فتاویٰ،
اور چودہ کتبِ احادیث — نماز کے اوقات، قبلہ نما اور ڈیجیٹل تسبیح سمیت۔ یہ ایپ
اس طرح بنائی گئی ہے کہ آپ کا مطالعہ آپ کے فون پر ہی رہے۔

یہ پالیسی بتاتی ہے کہ ایپ کیا کرتی ہے اور کیا نہیں۔ یہ ایپ کی اسٹور
لسٹنگز اور پروجیکٹ کی GitHub ریلیزز سے ملنے والی ایپ پر لاگو ہے۔

## خلاصہ

- **اشاعت کنندہ کی طرف سے کوئی ڈیٹا اکٹھا نہیں ہوتا۔** نہ کوئی اکاؤنٹ ہے، نہ
  ہمارا کوئی سرور، نہ اینالیٹکس، نہ اشتہارات، نہ کریش رپورٹنگ، نہ ٹریکنگ۔
  ایپ میں ایسا کوئی کوڈ نہیں جو آپ کے بک مارکس، نوٹ، پڑھنے کی جگہیں، تسبیح
  کے کاؤنٹ، ترتیبات یا کوئی اور معلومات کسی شخص کو بھیجے۔
- **سب کچھ آپ کے ڈیوائس پر محفوظ رہتا ہے** اور ایپ انسٹال کرنے (یا اس کا ڈیٹا
  صاف کرنے) پر ختم ہو جاتا ہے۔ ایپ کی بیک اپ سہولت سے آپ خود اپنا ڈیٹا فائل
  میں محفوظ کر سکتے ہیں تاکہ بعد میں بحال کر سکیں؛ وہ فائل صرف وہیں جاتی ہے
  جہاں آپ خود محفوظ کریں۔
- **انٹرنیٹ اختیاری ہے۔** انٹرنیٹ کے بغیر آپ ہر نصب شدہ کتاب پڑھ سکتے ہیں۔
  انٹرنیٹ صرف ان کاموں کے لیے استعمال ہوتا ہے: آپ کی درخواست پر کتابیں
  ڈاؤن لوڈ کرنا، آپ کی درخواست پر نماز/قبلہ کے لیے مقام معلوم کرنا، جگہ کے
  نام تلاش کرنا، اور آپ کے چھپائے گئے ماخذ کے صفحے کھولنا۔

## آپ کے ڈیوائس پر کیا محفوظ ہوتا ہے

ایپ یہ سب مقامی طور پر (ایپ کی ذاتی اسٹوریج اور اینڈرائیڈ کی ترتیبات میں)
رکھتی ہے:

- ڈاؤن لوڈ شدہ کتابوں کے ڈیٹابیس (جو دوبارہ ڈاؤن لوڈ ہو سکتے ہیں)؛
- بک مارکس اور آپ کے لکھے ہوئے نوٹ؛
- ہر کتاب میں آخری پڑھی ہوئی جگہ؛
- تسبیح کے کاؤنٹ اور محفوظ کردہ وِرد؛
- نماز کی ترتیبات (حساب کا طریقہ، ہجری تاریخ کی ایڈجسٹمنٹ، الرٹ) اور منتخب
  یا اجازت دیا گیا مقام (شہر کا نام اور کوآرڈینیٹس)؛
- تھیم، فونٹ اور متن کی ترتیبات؛
- آپ کے حالیہ تلاش کے الفاظ (تلاش کی تاریخچہ)۔

یہ سب ڈیوائس سے باہر نہیں جاتا، جب تک **آپ** خود بیک اپ فائل ایکسپورٹ کر کے
کہیں محفوظ نہ کریں۔

## انٹرنیٹ پر کیا جاتا ہے، اور کس کے پاس

ایپ کا اپنا کوئی سرور نہیں۔ جب آپ کوئی آن لائن فیچر استعمال کرتے ہیں، ایپ
صرف اس کام کے لیے ان تھری پارٹی سروسز سے رابطہ کرتی ہے:

1. **کتابوں کی ڈاؤن لوڈ (اختیاری)۔** جب آپ کتاب انسٹال کریں، ایپ HTTPS پر
   پروجیکٹ کی GitHub ریلیزز سے (`github.com`، `raw.githubusercontent.com`)
   ڈیٹابیس ڈاؤن لوڈ کرتی ہے۔ ٹوٹی ہوئی ڈاؤن لوڈ وہیں سے دوبارہ شروع ہوتی ہے۔
   ہر فائل کھولنے سے پہلے اس کی SHA-256 تصدیق ہوتی ہے۔ GitHub کے سرورز پر
   عام ویب سرور معلومات (جیسے IP ایڈریس اور یوزر ایجنٹ) نظر آتی ہیں، جیسے
   کسی بھی فائل ڈاؤن لوڈ پر۔
2. **IP سے تخمینی مقام (صرف جب GPS دستیاب نہ ہو اور آپ جاری رکھیں)۔** ایپ
   `ipapi.co` یا `ipwho.is` سے آپ کے IP ایڈریس کا تخمینی مقام پوچھتی ہے تاکہ
   آپ کے علاقے کے نماز کے اوقات پیش کیے جا سکیں۔ اس سروس کو آپ کا IP ایڈریس
   ضرور نظر آتا ہے۔ جواب آپ کے ڈیوائس پر کسی اور مقام کی طرح محفوظ ہوتا ہے۔
3. **جگہ کا نام تلاش کرنا (اختیاری)۔** کوآرڈینیٹس کو قابلِ پڑھائی جگہ کے نام
   («G-11، اسلام آباد») میں بدلنے یا آپ کے لکھے ہوئے شہر کے نام کی تلاش کے لیے
   ایپ کوآرڈینیٹس یا شہر کا نام OpenStreetMap کے Nominatim
   (`nominatim.openstreetmap.org`)، Open-Meteo کے geocoding API
   (`geocoding-api.open-meteo.com`)، یا BigDataCloud کے reverse-geocoding API
   (`api.bigdatacloud.net`) کو بھیجتی ہے۔ اس تلاش کے لیے صرف کوآرڈینیٹس یا
   لکھا ہوا نام ہی بھیجتا ہے۔
4. **براؤزر میں ماخذ کے صفحے (صرف جب آپ ان پر چھپیں)۔** کچھ فتاویٰ میں
   **اصل ماخذ پر جائیں** بٹن مرجع کی سرکاری ویب سائٹ پر فتویٰ کا اصل صفحہ
   آپ کے براؤزر میں کھولتا ہے۔ اس دوران وہ ویب سائٹ اپنی پالیسی کے مطابق
   عمل کرتی ہے۔

ایپ آپ کا GPS مقام اپنے کسی نظام کو نہیں بھیجتی؛ کوآرڈینیٹس ڈیوائس پر
استعمال ہوتے ہیں (نماز کے اوقات اور قبلہ کا زاویہ مقامی طور پر معلوم ہوتا ہے)
اور صرف اوپر بتائی گئی جگہ-نام سروسز کے ساتھ جاتے ہیں، وہ بھی تب جب جگہ کا
نام تلاش کیا جا رہا ہو۔

## اجازتیں

- **لوکیشن (درست/تخمینی):** چلتے وقت مانگی جاتی ہے، صرف نماز کے اوقات اور
  قبلہ کی سمت معلوم کرنے کے لیے۔ اگر آپ انکار کر دیں، ایپ آپ کے منتخب کردہ
  شہر (ایک آف لائن فہرست) کے ساتھ بالکل صحیح چلتی ہے — اور کچھ نہیں بدلتا۔
- **انٹرنیٹ:** اوپر بتائے گئے اختیاری ڈاؤن لوڈ اور تلاش کے لیے۔
- **کمپاس سینسر:** قبلہ ڈائیل کے لیے۔ سینسرز کو اجازت درکار نہیں اور کوئی
  ڈیٹا کہیں نہیں بھیجا جاتا۔

ایپ آپ کے رابطے، دوسری ایپس کی فائلز، مائیکروفون، کیمرہ، فون، SMS یا
نوٹیفکیشنز (نماز کے الرٹ صرف ایپ کے اندر ہیں) کی اجازت نہیں مانگتی، اور اس
میں اشتہار یا اینالیٹکس SDK نہیں ہیں۔

## بچے

ShiaVerse عمومی سامعین کے لیے ایک دینی لائبریری ہے۔ یہ 13 سال سے کم عمر
بچوں کے لیے نہیں ہے اور یہ کسی سے بھی، بچوں سمیت، کوئی ذاتی معلومات بے علم
اکٹھی نہیں کرتی۔

## ڈیٹا کا اشتراک یا فروخت

کوئی اشتراک یا فروخت نہیں ہے، کیونکہ کوئی ڈیٹا اکٹھا ہی نہیں ہوتا۔ ایپ میں
نہ کوئی تھری پارٹی SDK ہے جو ڈیٹا اکٹھا کرے، نہ اشتہاری نیٹ ورک، نہ اینالیٹکس۔

## حفاظت

کتابوں کے ڈیٹابیس استعمال سے پہلے SHA-256 ہیش سے تصدیق ہوتے ہیں، ایپ
غیر محفوظ (cleartext) کنکشنز قبول نہیں کرتی، اور نہ ہی کوئی اکاؤنٹ یا
سرور-سائیڈ اسٹور ہے جس میں خرابی ہو سکے۔ آپ کی ایکسپورٹ کردہ بیک اپ فائل
میں آپ کے بک مارکس، نوٹ اور ترتیبات ہوتے ہیں — اسے محفوظ کرتے وقت کسی ذاتی
فائل کی طرح سمجھیں۔

## آپ کے اختیارات

- کتابیں انسٹال کرنے کے بعد ایپ مکمل آف لائن استعمال کریں۔
- لوکیشن کی اجازت نہ دیں اور خود شہر منتخب کریں۔
- کسی بھی وقت **ترتیبات → بیک اپ و منتقلی** سے اپنا ڈیٹا ایکسپورٹ یا حذف
  کریں۔ ایپ انسٹال کرنے سے تمام مقامی ڈیٹا ختم ہو جاتا ہے۔

## پالیسی میں تبدیلیاں

کسی بھی تبدیلی کی اطلاع اس فائل میں پروجیکٹ کے ریپوزٹری میں دی جائے گی اور
متعلقہ ایپ اپ ڈیٹ کے ساتھ جاری ہو گی۔ اوپر کی تاریخ حالیہ نسخے کو ظاہر
کرتی ہے۔
